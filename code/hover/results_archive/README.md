# Archived results (not used in the proposal)

These files were computed on 10 November 2026 with the eye map that still gave the male bright zone a
finer lattice (corrected in `eye.py` on 11 November: Straw et al. 2006 report more light, not more
resolution) and under the earlier framing of hypothesis H2 (one median muscle that pulls both retinae
toward the midline). They document analyses that the scripts can repeat; no number in the proposal
depends on them.

| File | Produced by | Content |
|---|---|---|
| `adversarial_result.json` | `hover.adversarial` | controversial stimulus for two pull directions of the third muscle (one eye) |
| `adversarial_pixel_result.*` | `hover.adversarial_pixel` | pixel-level gradient search for the same question |
| `mio_ring_result.*` | `hover.mio_ring` | twelve pull directions, stimulus that isolates the third muscle |
| `binocular_result*.json`, `binocular_table.json` | `hover.binocular_search` | two-eye model with one median command; male-versus-female stimulus, dichoptic and single display |
| `mio_search_result.json` | `hover.mio_search` | first-generation front end (superseded) |

Current results: `../bowl_result.json`, `../eventcam_result.json`, `../results_raw/`.
