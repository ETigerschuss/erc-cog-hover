# Host institution support letter: points to secure

> The ERC prescribes a **mandatory template** for the host commitment letter. Download it
> from the Funding & Tenders portal. This list covers the extras to negotiate and, where possible, mention.

- [ ] Correct legal entity name and PIC number of IU
- [ ] PI employment for the full project duration (+ the right to hold the grant / portability)
- [ ] Teaching reduction during the grant (ERC: ≥ 40 % of time on the project)
- [ ] Lab space: fly rearing (climate chamber), eye-tracking/physiology rig room, robot lab
- [ ] HPC/GPU access or cloud credits
- [ ] PhD supervision: IU doctoral rights **or** a written co-supervision agreement (e.g., with a doctorate-granting university)
- [ ] Administrative support for EU grant management
- [ ] Matching funds (e.g., outreach coordinator, equipment)
- [ ] Conflict-of-interest handling (Backyard Brains) acknowledged

# Ethics self-assessment (Part A): expected flags
- Animals: insects only → generally "no", but describe 3R handling.
- Humans: yes, students and citizens (surveys, robot logs) → informed consent, GDPR, IU ethics committee.
- Personal data: yes (participant contact, survey) → DPO, data minimisation.
- Dual use / misuse: drone pursuit algorithms → consider and state "civil applications only; no military use".
